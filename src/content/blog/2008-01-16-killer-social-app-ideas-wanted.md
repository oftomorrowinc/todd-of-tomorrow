MyBlogLog has rolled out its long overdue API as an invite only beta. W00t!

It has some pretty cool features, if I do say so myself:

Get all the websites associated with a particular tag

Get all the members’ contacts on MyBlogLog

Lookup by ID on a service such as flickr or twitter and find profile on MyBlogLog

Get member profile data including sites authored, tags, and identities on other sites!

If you have a great idea for a killer distributed app, or a current application that could benefit from the MyBlogLog API, let us know the deets . If it sounds like a good fit, we will get you on the invite list. Facebook , OpenSocial , OpenID / oAuth devs: I’m talking to you.

BONUS: For helping to kick the tires on the new API, the best applications will be demoed on stage at a major tech event when we leave beta. (Disclaimer: The MyBlogLog API will not be in perpetual beta!)
